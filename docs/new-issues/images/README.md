# Visual Issue Evidence

Save screenshots in the matching issue folder using the issue number. Additional screenshots for the same issue use a decimal suffix. Issue 001 is intentionally documented without screenshots; the current files in `issue 002/` are for the Issue 002 solution/mockup.

- `issue002.png`
- `issue002.1.png`

Continue the suffix when more evidence is added, for example `issue002.2.png`.
